# 3D printing projects

Use this folder for **printer/slicer preparations**, for example a 3MF project with multiple placed objects, supports, orientation and printer settings.

For every print project document the machine and process (filament, resin or other), material, slicer/version, constituent component IDs, validated settings and whether external assets are required.

A new print attempt or different filament color is **not automatically a new CAD design revision**. Record print tests separately from design revisions. See [revision control](../../Documentation/standards/3d-revision-and-manufacturing.md).

Printer-specific proprietary formats should be checked before uploading. Never rely on a 3MF being identical to a standalone mesh simply because it can be printed.
