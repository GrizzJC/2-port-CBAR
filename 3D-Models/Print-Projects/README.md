# Print Projects

A print project records the settings and arrangement used to fabricate one or more parts. For example, a 3MF file may contain several components on one build plate, along with slicer information.

For each print project, record:

- The component identifiers and quantities being printed
- Printer and process (filament, resin or another method)
- Material, slicer application and relevant settings
- Orientation, supports and any critical setup
- Test/print outcome and the component revisions used

A change to infill, material color or printer does **not automatically** create a new mechanical design revision. Track fabrication changes and print results separately from the geometry's revision.

Use the [print project record template](../../Documentation/templates/print-project-record.md).
