# Individual components

Create **one folder per approved component identifier** only after the item's identity and number have been reviewed. The future folder may contain a record, a source file where authorized and format-specific exports. Do not create empty numbered folders for hypothetical components.

Copy [component-record.md](../../Documentation/templates/component-record.md) as the starting README. It must say what the part does, what it mates with, which source CAD version produced the export, and whether its manufacturing release is validated.

A .stl by itself is generally an exported mesh, not an editable parametric source. A .3mf may be a prepared build plate rather than a single part. Those are not interchangeable.
