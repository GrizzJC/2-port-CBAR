# 3D printing

3D-printable files are organized under [Systems](../Systems/README.md) → functional system → subgroup → `3D-Printing` rather than in a second flat file library. The [master inventory](../inventory.csv) is the authoritative searchable file list.

**3DP** means **additive manufacturing / 3D printing**, including filament and resin. It is not a label for every file made in CAD software. An STL normally represents printable mesh geometry. Each registered 3MF represents a prepared print job, even with one object. Print arrangements and printer/material compatibility must be verified rather than inferred from filenames.

The 112 imported printing files were moved without changing their binary contents. Preserve native CAD and executable dependencies when bringing in editable sources.
