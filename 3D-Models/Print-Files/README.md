# Printable files

[Version 1 printable file collection](V1/README.md) contains the initial source-preserved STL and 3MF files, with exact source paths and hashes indexed in [the V1 manifest](../../tracking/print-files-v1.csv).

This is a manufacturing-file intake collection. Editable CAD designs, assemblies and controlled print projects are documented separately once identified. Preserve source names to minimize manual renaming.
