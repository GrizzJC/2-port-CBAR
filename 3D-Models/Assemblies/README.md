# Assemblies

An assembly groups **multiple components and their spatial or mechanical relationships**. Keep linked native CAD references intact, especially SolidWorks `.sldasm` to `.sldprt` references and linked Fusion designs.

Use [assembly-record.md](../../Documentation/templates/assembly-record.md) to list component identifiers, mating relationships, alignment constraints and verified source versions.

Eventually an annotated assembly diagram can be added **after it is approved**. No diagrams or viewer code are included in this first organization phase.
