# Assemblies

An assembly defines how multiple components fit together. An assembly is not the same asset as each of its constituent parts.

Document the component identifiers and quantities, mating interfaces, source design location, any externally linked CAD files and the current assembly revision.

Use the [assembly record template](../../Documentation/templates/assembly-record.md).

**Reference integrity:** Native SolidWorks assemblies can depend on the names and paths of part files. Moving or renaming files outside the CAD application may break those links. Check and update references using the authoring software before adopting revised paths.
