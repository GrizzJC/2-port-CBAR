## 3. What the other directories are for

- **CNC:** Programs, projects and drawings for computer-controlled machining.
- **Code:** System-specific MATLAB, Arduino and other executable control files.
- **Electronics:** Electronic circuit boards, schematic source files and wiring designs.
- **Images-and-Diagrams:** System-specific reference images, photographs and explanatory diagrams.

These are folder locations, not additional functional systems. The last four folders contain placeholders only. **Do not interpret a placeholder as evidence that a file exists or has been verified.**
