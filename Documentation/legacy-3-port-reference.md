# Legacy 3-port source policy

Reference repository: https://github.com/neuroMoth/3-Port-4-Bottle-Rig

The existing repository was developed for a **3-port rig**, not the present 2-port task. It includes a historical mix of printable files, SolidWorks parts/assemblies, STEP exports, electronics and code. As inventoried 2026-11-02: 152 STL, 67 3MF, 171 SolidWorks parts, 18 SolidWorks assemblies and 109 STEP files across the entire old repository.

**Do not bulk-copy, rename or mark these files as current 2-port components.** Each proposed reuse requires review of physical compatibility, CAD links, file dependencies, quality/print tests, authorship, license conditions and Tim/Chad approval.

The older rig repository carries an **MIT** license file attributed to its original author. A separate older Bpod software repository is identified by GitHub as GPL-3.0. Do not assume their licenses automatically apply to all newly created files or to third-party components. Check file-level rights before any migration.

The 2-port registry starts empty until actual new 2-port source assets are available and verified.
